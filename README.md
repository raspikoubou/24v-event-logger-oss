# 設備イベントロガー / 24V Event Logger

らずぱい工房の24V I/O HATとRaspberry Piを使用して、設備の24Vデジタル信号を記録するソフトウェアです。PC・スマートフォンのWebブラウザから、記録の確認や設定変更を行えます。

## 主な機能

- IN1〜IN6のON/OFF変化を時刻とともに記録
- ダッシュボードで現在状態、イベント回数、ON/OFF時間などを表示
- 履歴の検索とCSV保存
- OUT1〜OUT6によるHeartbeat、診断、簡易条件通知

対象環境：Raspberry Pi 5（メモリー4GB以上）、Raspberry Pi OS Lite 64-bit（Debian 13）、らずぱい工房 24V I/O HAT。

## 使用上の注意

本ソフトウェアは設備信号の記録と簡易通知のためのもので、非常停止や人身安全制御には使用できません。Web画面はHTTP通信のため暗号化されません。信頼できるLAN内で使用し、共有パスワードによる保護を有効にしてください。インターネットへ直接公開しないでください。詳しくは[概要説明書](docs/概要説明書.md)および[取扱説明書](docs/取扱説明書.md)を参照してください。
