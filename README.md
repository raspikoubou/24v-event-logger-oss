# 設備イベントロガー / 24V Event Logger

らずぱい工房の24V I/O HATとRaspberry Piを使用して、設備の24Vデジタル信号を記録するソフトウェアです。PC・スマートフォンのWebブラウザから、記録の確認や設定変更を行えます。

## 主な機能

- IN1〜IN6のON/OFF変化を時刻とともに記録
- ダッシュボードで現在状態、イベント回数、ON/OFF時間などを表示
- 履歴の検索とCSV保存
- OUT1〜OUT6によるHeartbeat、診断、簡易条件通知

対象環境：Raspberry Pi 5（メモリー4GB以上）、Raspberry Pi OS Lite 64-bit（Debian 13）、らずぱい工房 24V I/O HAT。

## 使用上の注意

本ソフトウェアは設備信号の記録・表示と補助的な通知を目的としています。**非常停止、人身安全制御、安全インターロック、設備保護など、誤動作が人身事故や設備損傷につながる安全制御用途を想定しておらず、その用途に必要な動作・信頼性を保証しません。** 安全確保に必要な機能は、本ソフトウェアとは独立した機器・回路で実現してください。これは安全上の警告であり、MIT Licenseの利用許諾に用途制限を追加するものではありません。

停電、機器・SDの故障、処理遅延、保存失敗などにより、入力変化の見落とし、記録の欠落・消失、表示の遅延が発生する場合があります。OUTでは意図しないON/OFF、出力の遅れ、出力されない状態が発生する可能性があり、出力時刻や状態は保証されません。画面上のOUT履歴は出力指示の記録であり、接続先機器の実際の動作を測定したものではありません。

Web画面はHTTP通信のため暗号化されません。信頼できるLAN内で使用し、共有パスワードによる保護を有効にしてください。インターネットへ直接公開しないでください。詳しくは[概要説明書](docs/概要説明書.md)および[取扱説明書](docs/取扱説明書.md)を参照してください。
