# 0.1.6 — 設備イベントロガー

Raspberry Pi 5（メモリー4GB以上）とらずぱい工房24V I/O HAT向けのローカルWebロガーです。Raspberry Pi OS Lite 64-bit／Debian 13、Python 3.13を対象とします。

## 主な機能

- 6入力のON/OFF変化を記録し、履歴・CSV・ウィジェットで確認できます。
- Heartbeat、診断、簡易条件通知にPNP出力を使用できます。
- 明示的に記録を停止した状態を、再起動後も維持します。

導入方法は[インストール説明書](インストール説明書.md)、操作方法は[取扱説明書](取扱説明書.md)を参照してください。最新の変更点と配布ファイルは[GitHub Releases](https://github.com/raspikoubou/24v-event-logger-oss/releases/latest)から確認できます。

安全制御・非常停止には使用できません。HTTP通信のため、信頼できるLAN内で使用してください。重要な記録は定期的にCSVで保存してください。
