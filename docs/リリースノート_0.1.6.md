# 0.1.6 — 設備イベントロガー（Release下書き）

Raspberry Pi 5（RAM 4GB以上）とらずぱい工房24V I/O HAT向けのローカルWebロガーです。Raspberry Pi OS Lite 64-bit／Debian 13、Python 3.13を対象とします。MIT License。

## 内容

- 6入力のON/OFF変化記録、履歴、CSV、ウィジェット。
- PNP Heartbeat、診断、簡易条件通知。
- 明示した記録停止状態を再起動・バックアップ復元後も保持。
- private SQLite 3.53.4、Gunicorn 26.2.0、systemd導入・更新・health失敗時の復帰。

Web・DB・フロントエンドの責務を分離し、容量未計測時の誤表示、ログ検索条件変更時の期間流用、出力ルール取り消し時の監査日時を修正しました。HTTP endpoint、DBスキーマ、GPIO割当は維持しています。

## 確認と制約

今回の候補はMacでPython 372件、型チェック74ファイル、JavaScript 10 suiteを確認しました。今回のリファクタリングを含む配布ファイルの実Pi検証は未実施です。以下は変更前の0.1.6配布ファイル・基準候補の試験結果であり、今回の候補の実機検証を意味しません。

変更前の0.1.6配布ファイルで実Piの更新に成功し、全10テーブル・設定一致、入力96件／出力108件、記録停止・全OUT OFF・pending 0を確認しました。基準候補の実Piで導入、LAN初回設定、停止後再起動、6組PNP OUT→IN、48件CSV照合、ローカルasset更新とhealth失敗時の自動rollbackを確認済み。独立した入力刺激・波形測定、公開GitHubからのWeb更新、schema変更を伴う復帰、24時間運転は未確認です。6組loopbackは入力波形や同時入力性能の保証ではありません。

このReleaseは下書きで、利用者向け配布は開始していません。導入手順は[インストール説明書](インストール説明書.md)、使用上の注意や操作方法は[取扱説明書](取扱説明書.md)を参照してください。安全制御・非常停止には使用しません。HTTPは信頼できるLAN内で利用します。
