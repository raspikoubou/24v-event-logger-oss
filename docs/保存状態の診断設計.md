# 記録の保存待ちと警告表示

## 保存待ちとは

入力を確定してからSDへの保存が完了するまで、一時的に未保存の記録が残ることがあります。保存待ちの間も入力の記録処理を継続しますが、OSの負荷や機器の状態による影響まで保証するものではありません。記録時刻は保存完了時刻に置き換えません。

未保存の記録は最大10,000件まで一時保持します。電源断やソフトウェアの終了では失われる可能性があります。保存できない状態や保持上限に達した場合は、重大な異常として記録を停止します。保存遅延の表示だけでは、欠落の有無は判断できません。注意・警告が出ていなくても、すべての入力変化の検知と記録保存が保証されるわけではありません。短い信号の見落としや、異常時の記録欠落がすべて検出・表示されるとは限りません。

## 診断画面の読み方

「ログ保存遅延（直近5分）」には、500ms以上かかった保存の回数・最大時間、未保存の最長滞留時間、未保存件数を表示します。500msは注意表示の基準であり、記録欠損や機器故障を示す境界ではありません。

| 状態 | 表示条件 | 確認する場所 |
|---|---|---|
| 正常 | 下記に該当しない | 診断画面 |
| 注意 | 直近5分に500ms以上の保存がある、または現在の保存・滞留が500ms以上 | 診断画面の注意欄 |
| 警告 | 現在の保存・滞留が5秒以上、未保存件数が上限の80%以上、または保存処理の失敗 | 各画面の注意欄と診断画面 |

警告は、保存失敗がなく、保存・滞留がともに1秒未満、未保存件数が上限の50%未満の状態を10秒間維持すると解除されます。保存処理そのものが失敗した場合は、原因を解消してからソフトウェアを再起動する必要があります。

注意は、直近5分の遅延記録がなくなり、現在の保存・滞留も500ms未満になると解除されます。画面の更新間隔より短い変化をすべて表示できるわけではありません。

## 警告が出たとき

未保存件数と滞留時間が減るか、SDの空き容量や他の異常表示を確認してください。保存待ちが残っている間は電源を切らず、必要な履歴はCSVで別媒体へ保存してください。警告が続く場合の確認方法は[取扱説明書](取扱説明書.md)を参照してください。
